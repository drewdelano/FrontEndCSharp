# Interop.JS.LucideIcons

Managed bindings for the canonical `lucide-react@1.72.0` icon catalog. The public
`LucideIcons` facade exposes one concrete FECSX component for each of the 2,032
non-deprecated canonical upstream
icon with shared typed icon properties. Deprecated re-export aliases, dynamic
name lookup, opaque React handles, and raw import signatures remain outside the
public surface.
