# FrontEndCSharp.Overrides.Interop.JS.LucideIcons.fecs

Runtime-override companion for the canonical `lucide-react@1.72.0` bindings.
React is a peer supplied by `Interop.JS.React`. Each of the 2,032 non-deprecated canonical icons
has an independent static import so unused icons remain outside browser output;
deprecated re-export aliases are not generated.
