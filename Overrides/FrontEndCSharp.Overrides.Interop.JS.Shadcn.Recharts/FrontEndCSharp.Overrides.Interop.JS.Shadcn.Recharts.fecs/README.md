# FrontEndCSharp.Overrides.Interop.JS.Shadcn.Recharts.fecs

Runtime-override companion for the selected `recharts@3.8.0` bindings. It owns the
library's private `react-is@19.3.1` runtime dependency while React and React DOM are
peers supplied by `Interop.JS.React`. Only reachable overrides enter browser output.
